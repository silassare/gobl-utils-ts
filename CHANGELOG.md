### Unreleased (2.1.x-dev)

-   `GoblRowOf<E, P>`: the row of an entity, derived from it. An entity exposes
    its columns unprefixed (`name`) while a row carries them prefixed
    (`file_name`), which is what a REST answer and a form submission hold. What
    is not a column (the members of `GoblEntity`, and the helpers an entity
    declares such as `singlePKValue()`) is excluded by shape, a column never
    being a function. The TypeScript bundle Gobl generates declares one per
    entity (`OZFileRow`) and imports this type, so a bundle generated by a
    Gobl release that declares rows needs this release, not v2.0.0.

### v2.0.0 (2026-09-19)

-   Importing the package no longer replaces the global `JSON.parse`: use
    `parseGoblJSON()` or `goblJSONReviver`.
-   `cacheKey()` is always a string: the primary key value (`0` included), or,
    for a composite primary key, the JSON array of its values in column name
    order; `null` when a primary key value is missing.
-   `toInstance()` no longer removes the marker from the data it is given;
    `register()` no longer sorts the entity class's `COLUMNS`.
-   `_bool()` returns `null` for `null` / `undefined`; `_int()` returns `null`
    for them and for what is not a number.
